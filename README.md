# 万能下载器

TAVOR 制作的 Windows 视频下载工具正式发布页。

## 下载与安装

请前往 [Releases](../../releases) 下载最新的 `Universal-Downloader-Windows-x64-Setup.exe`，双击后按中文安装向导完成安装。

- 支持平台：B站、抖音、YouTube、小红书
- 系统要求：Windows 10 或更高版本（64 位）
- 更新：软件会在主界面显示后检查可信更新；更新包和元数据均会校验签名。

## 1.7

- 首次启动的本地许可确认
- 启动、许可、工作区统一为一个窗口
- 设置页按“软件更新 / 隐私与登录 / 关于软件”分层
- 安装目录关键程序完整性校验

本仓库仅保存公开发布所需的安装程序和 `update.json`，不包含源码、日志或缓存文件。
