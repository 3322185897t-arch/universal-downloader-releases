普通用户只需要下载 `Universal-Downloader-Windows-x64-Setup.exe`（Windows 正式安装器）。`update.json` 是软件自动更新使用的签名校验文件，不需要手动下载；GitHub 自动生成的 Source code（源码归档）不是可运行软件。

## 平台与主要功能

- **B站**：普通单视频解析、封面与清晰度展示、扫码登录、视频下载及音视频合并。
- **抖音**：视频链接解析、封面预览、视频下载，以及真实下载进度、大小和速度反馈。
- **YouTube**：视频解析与下载、清晰度选择、浏览器登录状态使用和分阶段任务反馈。
- **小红书**：视频与图文笔记解析、封面和内容预览、视频及图片下载。
- **统一操作**：选择保存位置、取消任务、查看任务状态、打开下载文件及保存目录。
- **系统设置**：软件更新、隐私与登录状态管理、组件诊断及软件信息。

## 从旧版本升级

打开软件：**设置 → 软件更新 → 检查更新 → 立即更新**。

软件会下载正式安装器，校验数字签名、文件大小及 SHA-256 指纹，再启动安装程序。按提示完成安装并重新打开软件。正常升级不会删除原有登录状态、设置和已下载文件。

检查更新需要能正常访问 GitHub。若旧版提示“GitHub 暂时受限”或网络请求失败，可直接通过上面的官方安装器覆盖安装，无需先卸载。
